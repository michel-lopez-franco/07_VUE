# Trabajo Libre 06: Aplicación Vue.js - Gestor de Tareas

Aplicación web funcional desarrollada con **Vue 3** y **Vite**, que demuestra el uso de reactividad, componentes, manejo de eventos y estado.

## 📋 Descripción y Propósito

Esta aplicación permite gestionar una lista de tareas interactivas. El objetivo del proyecto es aplicar los conceptos fundamentales del ecosistema de Vue:
- **Reactividad**: Manejo dinámico del estado mediante la Composition API (`ref`).
- **Componentes**: Separación de la interfaz en componentes reutilizables (`TaskCard.vue`).
- **Manejo de Eventos**: Comunicación entre componentes hijo y padre utilizando `emit`.
- **Renderizado Condicional y de Listas**: Uso de directivas `v-for`, `v-if` y binding de clases con `:class`.

## 🛠️ Tecnologías Utilizadas

- **Framework**: Vue.js 3 (Composition API)
- **Tooling**: Vite
- **Despliegue**: Vercel
